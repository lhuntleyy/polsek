# 22 — Jadwal Review Bulanan

**Peserta:** Kapolsek, Pawas, Admin, DPO (bila perlu).
**Durasi:** 60 menit.

| Waktu | Agenda | Output |
|---|---|---|
| 10' | Angka bulan lalu: total, P1, SLA, duplikat | Catatan |
| 10' | Insiden: WA disconnect, data, bug | Tindakan |
| 10' | Audit log & akses PII | Temuan |
| 10' | Backup/restore dan kapasitas | Status |
| 10' | SOP, polygon, nomor, petugas | Perubahan |
| 10' | Action item + PIC + deadline | Daftar tugas |

## Checklist
- [ ] Backup terakhir < 24 jam.
- [ ] Restore drill bulan ini lulus.
- [ ] Tidak ada P1/P2 terbuka.
- [ ] TOTP semua petugas aktif.
- [ ] Nomor WA dan grup URC benar.
- [ ] Polygon resmi masih berlaku.
- [ ] Audit anomali ditindaklanjuti.
- [ ] Retensi/legal hold sesuai.
- [ ] Pelatihan/poster diperbarui.

## Output
- Notulen 1 halaman.
- Action item masuk backlog.
- Review berikutnya dijadwalkan.
