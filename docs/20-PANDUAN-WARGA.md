# 20 — Panduan Warga (Poster)

Poster siap cetak: `docs/assets/poster-warga.png` / `.svg`.

## Cara lapor
1. Scan QR atau simpan nomor WhatsApp Polsek.
2. Kirim pesan **LAPOR**.
3. Tulis nama lengkap.
4. Pilih jenis laporan.
5. Ceritakan kejadian.
6. Kirim lokasi kejadian (share location) — bukan lokasi rumah jika berbeda.
7. Kirim foto/video/voice note jika ada.
8. Simpan nomor tiket.

## Darurat
- Tawuran, kebakaran, begal, kecelakaan, orang meninggal: ketik **DARURAT** atau langsung kirim lokasi.
- Untuk nyawa terancam, telepon **110** atau **112**.

## Privasi
- Nama wajib untuk tindak lanjut.
- Nomor hanya dipakai untuk penanganan laporan.
- Nomor ditampilkan masked di dashboard petugas.
- Foto/video disimpan sebagai bukti, bukan untuk disebarkan.

## Luar wilayah
Jika lokasi di luar wilayah hukum Polsek, sistem mengarahkan ke 110/Polsek terdekat.
