# 19 — Panduan Piket (1 Halaman)

## Saat mulai shift
1. Login + TOTP.
2. Aktifkan suara alarm.
3. Cek antrean, P1, tiket tunda.
4. Baca catatan serah terima sebelumnya.

## Menerima tiket
1. Klik tiket di antrean atau pin peta.
2. Cek nama, nomor (masked), lokasi, media.
3. Klik **Terima Laporan**.
4. Jika perlu, tampilkan nomor (30 detik, tercatat audit).

## Ke TKP
1. Klik **OTW ke TKP**.
2. Koordinasi URC/grup.
3. Klik **Tiba di TKP** saat tiba.

## Menutup
1. Isi catatan penanganan.
2. Klik **Selesaikan**.
3. Pastikan pelapor menerima update.
4. Jangan menutup tanpa bukti/catatan.

## P1 / darurat
- Alarm berbunyi; buka tiket.
- Ack ≤ 2 menit, OTW ≤ 5 menit.
- Jika tidak direspons: eskalasi Pawas (3 menit) dan Kapolsek (10 menit).
- Hubungi 110/112 jika nyawa terancam.

## Duplikat
- Detail tiket menampilkan **Kemungkinan duplikat**.
- Cek lokasi/waktu; klik **Gabung** jika sama.
- Tiket sumber dibatalkan, media pindah.

## Serah terima
- **Serah** → checklist → catatan → nama petugas masuk → tanda tangan.
- Pastikan P1, tunda, dan tiket tanpa nama sudah dicek.

## Jangan
- Menyebarkan foto/nomor ke luar kanal resmi.
- Menutup tiket palsu.
- Memakai akun orang lain.
